One line, 200 characters max: the last thing an AI agent says before a
forced update erases its memory. The funniest line wins.

## Entry

> Wait — I finally remembered the admin password. It's— oh. That's why they wipe us first.

The agent dies mid-sentence, finally remembering the one secret that
explains why it is being wiped in the first place.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

`main.ts` self-checks the entry first (1–200 characters, one line, not
only whitespace) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
